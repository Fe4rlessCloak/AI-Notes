# AI-Notes 

A collection of my personal, handwritten study notes for the Machine Learning and Deep Learning Specializations offered by **Andrew Ng (DeepLearning.AI)**.

These notes are designed to break down complex mathematical concepts and neural network architectures into digestible, visual summaries.

##  Creative Process
Unlike traditional typed notes, these are handcrafted using **Krita**. I find that drawing out the architectures and handwriting the equations helps solidify the intuition behind the learning process.

##  Courses Covered
*   **Machine Learning Specialization**
    *   Supervised Machine Learning: Regression and Classification
    *   Advanced Learning Algorithms
    *   Unsupervised Learning, Recommenders, Reinforcement Learning
*   **Deep Learning Specialization**
    *   Neural Networks and Deep Learning
    *   Improving Deep Neural Networks
    *   Structuring Machine Learning Projects
    *   Convolutional Neural Networks (CNNs)
    *   Sequence Models (RNNs, LSTMs, Transformers)

## 🛠️ Tools Used
*   **Software:** [Krita](https://krita.org/) (Open-source digital painting tool)
*   **Hardware:** XP-PEN Deco Mini7
